# SKAsia IPTVX Full M3U — Option B

This package contains full IPTVX-ready M3U playlists for both SKAsia accounts:

- Live TV
- Movies
- Series

For every Live TV channel, `tvg-id` has been rewritten to the numeric Xtream
`stream_id`. This matches the channel IDs generated by the V5 XMLTV workflow.

Movies and Series are preserved, but their `tvg-id` is left blank so IPTVX does
not try to attach Live TV schedules to VOD content.

## IPTVX setup

Create a new M3U playlist for each account. Do not overwrite the existing Xtream
accounts until the new M3U playlists have been tested.

For each new playlist:

1. Select M3U playlist.
2. Enter the matching GitHub Pages M3U URL.
3. Enter the matching GitHub Pages XMLTV URL.
4. Save.
5. Force playlist and EPG refresh.
6. Test mainstream channels such as TV3, HBO, AXN or CNA.

## Security note

These M3U files contain your private SKAsia stream URLs and login credentials.
A public GitHub repository will expose them to anyone who knows or discovers the
URL. For safety, use a private repository with a private hosting method, or rotate
your SKAsia passwords after testing. GitHub Pages from a public repository is not
appropriate for permanent hosting of credential-bearing M3U playlists.
